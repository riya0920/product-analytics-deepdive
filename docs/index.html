What this project actually found

Simpson's paradox is a reporting bug waiting to happen

An aggregate can move the opposite way to every segment inside it. The segmentation layer checks for the reversal rather than trusting the top line.

Thin cells get suppressed, not rounded

A segment with too few users produces a number that looks precise and is noise. Those cells are withheld, because a suppressed cell is honest and a noisy one is not.

Physical layout changed query time more than the query did

Three storage layouts were measured against the same queries. The clustering choice moved runtime more than rewriting the SQL, which is the opposite of where tuning effort usually goes.

Incrementality is not the same as attribution

Attributed conversions include people who would have converted anyway. The analysis separates the two and is explicit that a real geo holdout needs a live ad account.
